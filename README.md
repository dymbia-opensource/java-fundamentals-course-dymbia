# Java desde cero: crea tu propio videojuego por consola

## Resumen del Curso
Este curso de 1 hora introduce a estudiantes de secundaria a los fundamentos de la programación con Java, incluyendo programación orientada a objetos (POO). A lo largo de 8 lecciones cortas construirás, paso a paso, un videojuego de consola llamado **Arena Pixel**. **¡No requiere descargas!** Solo abre tu navegador web.

**Duración total**: ~60 minutos

**Público Objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación

**Prerrequisitos**: Ninguno

**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)

**Repositorio de Código Fuente**: [https://github.com/dymbia-opensource/java-fundamentals-course-dymbia.git](https://github.com/dymbia-opensource/java-fundamentals-course-dymbia.git)



## Cómo usar este curso
1. Mira el video de la lección.
2. Abre el editor en línea de la lección (no necesitas registrarte).
3. Copia el archivo base de la carpeta `starter-files` y completa los `// TODO`.
4. Compara con la solución en `completed-examples`.
5. Si quieres saber qué se dice en cada video, revisa la carpeta `scripts`.

## Secuencia de la Lección

### Lección 1: Hola, Java: tu primer código (5 minutos)
- **Descripción**: Aprende qué es programar y por qué Java es un excelente lenguaje para empezar.
- **Enlace**: [Ver la lección](https://youtu.be/oMY2iObiD0s)
- **Conclusiones clave**: Programar es dar instrucciones a una computadora; `System.out.println("¡Hola!");` muestra texto en la consola.
- **Práctica**: [Clic para programar](https://onlinegdb.com/REEMPLAZAR-EDITOR-01)  **¡No es necesario registrarse!**
- **Archivos**: [`starter-files/leccion-01-hola-java`](starter-files/leccion-01-hola-java/Main.java) · [`completed-examples/leccion-01-hola-java`](completed-examples/leccion-01-hola-java/Main.java) · [Guion](scripts/leccion-01-guion.md)

### Lección 2: Variables: la ficha de tu personaje (6 minutos)
- **Descripción**: Aprende a almacenar datos en Java usando variables.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=jCrOzrxM2og)
- **Conclusiones clave**: Usa `String`, `int`, `double` y `boolean`; declara como `int nivel = 1;`.
- **Práctica**: [Clic para programar](https://www.jdoodle.com/online-java-compiler) **¡No es necesario registrarse!**
- **Archivos**: [`starter-files/leccion-02-variables`](starter-files/leccion-02-variables/Main.java) · [`completed-examples/leccion-02-variables`](completed-examples/leccion-02-variables/Main.java) · [Guion](scripts/leccion-02-guion.md)

### Lección 3: Operadores y decisiones: ¿pasas de nivel? (7 minutos)
- **Descripción**: Haz cálculos y toma decisiones con `if / else if / else`.
- **Enlace**: [Ver la lección](https://youtu.be/TmpXYS1uTAk)
- **Conclusiones clave**: `if (nivel >= 5 && tieneLlave) { }`; `%` da el residuo de una división.
- **Práctica**: [Clic para programar](https://onlinegdb.com/REEMPLAZAR-EDITOR-03)  **¡Inicio inmediato!**
- **Archivos**: [`starter-files/leccion-03-decisiones`](starter-files/leccion-03-decisiones/Main.java) · [`completed-examples/leccion-03-decisiones`](completed-examples/leccion-03-decisiones/Main.java) · [Guion](scripts/leccion-03-guion.md)

### Lección 4: Bucles: repite sin cansarte (6 minutos)
- **Descripción**: Repite tareas con `for` y `while`, y aprende a evitar los bucles infinitos.
- **Enlace**: [Ver la lección](https://youtu.be/oMY2iObiD0s)
- **Conclusiones clave**: `for (int i = 0; i < 5; i++) { }`; un `while` necesita algo que lo termine.
- **Práctica**: [Clic para programar](https://onlinegdb.com/REEMPLAZAR-EDITOR-04)  **¡Inicio inmediato!**
- **Archivos**: [`starter-files/leccion-04-bucles`](starter-files/leccion-04-bucles/Main.java) · [`completed-examples/leccion-04-bucles`](completed-examples/leccion-04-bucles/Main.java) · [Guion](scripts/leccion-04-guion.md)

### Lección 5: Métodos y Scanner: conversa con tu programa (8 minutos)
- **Descripción**: Crea código reutilizable con métodos y obtén datos del jugador con `Scanner`.
- **Enlace**: [Ver la lección](https://youtu.be/0dUFjvZIbdM)
- **Conclusiones clave**: `static int calcularDanio(int nivel) { return nivel * 5; }`; `Scanner` lee lo que escribe el jugador.
- **Práctica**: [Haz clic para practicar](https://www.jdoodle.com/ga/kupx-w78g-e6db)  **¡No necesitas registrarte!**
- **Archivos**: [`starter-files/leccion-05-metodos-scanner`](starter-files/leccion-05-metodos-scanner/Main.java) · [`completed-examples/leccion-05-metodos-scanner`](completed-examples/leccion-05-metodos-scanner/Main.java) · [Guion](scripts/leccion-05-guion.md)

### Lección 6: Clases y objetos: fabrica tus personajes (8 minutos)
- **Descripción**: Construye clases con atributos, constructor y métodos, y crea objetos con `new`.
- **Enlace**: [Ver la lección](https://youtu.be/TGmnvwiVizw)
- **Conclusiones clave**: Una clase es un plano y un objeto es lo que se fabrica con ese plano; `new Personaje("Luna", 1)`.
- **Práctica**: [Haz clic para practicar](https://www.jdoodle.com/ga/2xxn-p6ur-3f5s)  **¡No necesitas registrarte!**
- **Archivos**: [`starter-files/leccion-06-clases-objetos`](starter-files/leccion-06-clases-objetos/Main.java) · [`completed-examples/leccion-06-clases-objetos`](completed-examples/leccion-06-clases-objetos/Main.java) · [Guion](scripts/leccion-06-guion.md)

### Lección 7: Encapsulación y arreglos: protege a tu equipo (8 minutos)
- **Descripción**: Protege los datos con `private`, getters y setters, y guarda varios objetos en un arreglo.
- **Enlace**: [Ver la lección](https://youtu.be/awH2kHWq51E)
- **Conclusiones clave**: `private int vida;` con `getVida()` y `setVida(...)`; los arreglos empiezan en la posición 0.
- **Práctica**: [Haz clic para practicar](https://onlinegdb.com/REEMPLAZAR-EDITOR-07)  **¡No necesitas registrarte!**
- **Archivos**: [`starter-files/leccion-07-encapsulacion-arreglos`](starter-files/leccion-07-encapsulacion-arreglos/Main.java) · [`completed-examples/leccion-07-encapsulacion-arreglos`](completed-examples/leccion-07-encapsulacion-arreglos/Main.java) · [Guion](scripts/leccion-07-guion.md)

### Lección 8: Proyecto final Arena Pixel y errores comunes (12 minutos)
- **Descripción**: Integra todo lo aprendido en un videojuego por consola y repasa los errores más comunes de los principiantes.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR-VIDEO-08)
- **Conclusiones clave**: Un programa completo combina clases, `Scanner`, decisiones, bucles y arreglos; lee siempre el mensaje de error.
- **Proyecto final**: [Crea tu aplicación POO](https://onlinegdb.com/REEMPLAZAR-EDITOR-08)  **¡Guarda y comparte!**
- **Archivos**: [`starter-files/leccion-08-arena-pixel`](starter-files/leccion-08-arena-pixel/Main.java) · [`completed-examples/leccion-08-arena-pixel`](completed-examples/leccion-08-arena-pixel/Main.java) · [Guion](scripts/leccion-08-guion.md)
